# Future Money Lab

Production system for the YouTube channel **Future Money Lab** (@TheFutureMoneyLabAI): AI tools & smart money, tested and explained.

- `pipeline/` — turns an `episode.json` (script + scene data) into a finished 1080p video: natural AI voice (Chatterbox),
  normal 160 wpm pace, animated scenes over stock footage (Remotion), word-timed captions, music and sound effects,
  two thumbnails and a YouTube description with chapters.
- `episodes/` — one folder per video. `E01` is the first published episode and the template for new ones.
- `CLAUDE.md` — the step-by-step run book Claude follows on every scheduled production run.

Finished video files are only placed here briefly so Metricool can pick them up, then removed.
